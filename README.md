# Ricettario

App web (PWA) per salvare le ricette passo dopo passo. Tab per tipologia, tag e preferite; commento personale in visualizzazione.
Le ricette sono salvate nel browser (localStorage).

## Pubblicazione con GitHub Pages
1. Crea un repository su GitHub e carica tutti questi file nella radice.
2. Settings → Pages → Source: "Deploy from a branch" → branch `main`, cartella `/ (root)`.
3. Apri l'indirizzo `https://TUO-UTENTE.github.io/NOME-REPO/` in Safari su iPhone.
4. Condividi → "Aggiungi alla schermata Home".
